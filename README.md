# 3d-rpg-demo

Three.js 기반 3D RPG 게임 데모 프로젝트입니다. 아직 초기 단계이며, 이 저장소는 본격적인 개발을 시작하기 위한 뼈대(scaffold)입니다.

## 현재 포함된 것

- Vite + Three.js 개발 환경
- 3인칭 카메라(마우스 드래그로 시점 회전)
- WASD 이동, 간단한 캐릭터/카메라 추적
- 임시 지형(그리드 바닥), 장애물 블록, 플레이스홀더 적(enemy)
- 체력바 HUD

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

프로덕션 빌드:

```bash
npm run build
```

## 조작법

- `W` `A` `S` `D`: 이동
- 마우스 드래그: 시점 회전
- (예정) `Space`: 점프, 좌클릭: 공격
